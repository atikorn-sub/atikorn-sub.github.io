# รูปภาพของเว็บ

วางไฟล์รูปไว้ตามโฟลเดอร์นี้ แล้วชื่อไฟล์ต้องตรงกับที่เขียนใน `data.js` (ช่อง `images` / `certificates`)

| โฟลเดอร์ | ใช้กับ |
|---|---|
| `projects/` | รูปผลงานในการ์ดโปรเจกต์ (เช่น `helpdesk-1.jpg`) |
| `achievements/` | รูปประกอบรางวัล (เช่น `cwie-1st-1.jpg`) |
| `certificates/` | รูปเกียรติบัตร (เช่น `cert-01.jpg`) |

คำแนะนำ: ย่อรูปเป็น `.webp` หรือ `.jpg` กว้างไม่เกิน 1600 px ไฟล์ละไม่เกิน ~300 KB
